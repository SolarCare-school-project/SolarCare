## Jobs to be Done

**Main job:**
> "When my solar system is running, I want to be sure it delivers full yield and that nothing breaks unexpectedly, so that my investment pays off."

### Job Types

| Type | Job the customer wants done |
|---|---|
| **Functional** | Detect faults and yield losses early |
| **Functional** | Know which component is affected and how urgent it is |
| **Functional** | Plan maintenance and replacement before something fails |
| **Functional** | Connect a third-party technician quickly when a repair is needed & which exact component to replace |
| **Functional** | Keep a record of the system's history (warranty, insurance, house sale) |
| **Emotional** | Feel confident that the PV investment is protected |
| **Emotional** | Stay in control without needing technical knowledge |
